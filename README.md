## 🌟 عن المشروع

**ميموريا (Memoria)** هي منصة رقمية متكاملة تهدف إلى ربط العرائس بأفضل المصورات المحترفات. صُممت المنصة لتسهيل رحلة الحجز بالكامل؛ بدءاً من استعراض معرض الأعمال والباقات، مروراً بتأكيد الحجز ورفع إيصالات الدفع، وصولاً إلى تتبع مراحل الإنتاج وتسليم الصور النهائية. 

تم بناء المنصة على فلسفة تصميم (Don't Make Me Think) لتقديم واجهة مستخدم عصرية، سهلة، وخالية من التعقيد.

## ✨ الميزات الرئيسية

### 📸 للمصورات (لوحة تحكم احترافية)
* **معرض أعمال متكامل:** صفحة شخصية جذابة لعرض أفضل الصور وجذب العملاء المحتملين.
* **باقات تسعير ذكية (One-Click Templates):** إدارة مرنة للباقات الأساسية والإضافات مع تمييز الباقة المفضلة بصرياً (Visual Anchor) لتسهيل قرار العميل.
* **إدارة الحجوزات المتقدمة (Kanban):** لوحة تتبع شاملة لحالة كل حجز (بانتظار العربون، جاري التعديل، جاهز للتسليم).
* **إدارة العقود والإيصالات:** نظام آمن لمراجعة إيصالات التحويل البنكي وتأكيدها.
* **التواصل الذكي:** أزرار جاهزة للتواصل السريع عبر WhatsApp مع نصوص مجهزة مسبقاً لتوفير الوقت.
* **النموذج المختلط للتسليم:** تخزين ذكي يوفر المساحة؛ عبر استقبال إيصالات الدفع في المنصة، وتوفير حقل مخصص لروابط التسليم النهائي (Google Drive / WeTransfer) للعميل.

### 👰 للعميلات (تجربة حجز سلسة)
* **تصفح مرن:** استعراض باقات المصورة وحجز الموعد بخطوات بسيطة وواضحة.
* **صفحة تتبع خاصة بكل حجز:** يحصل العميل على رابط سري وخاص لتتبع حالة حجزه، رفع إيصال العربون، ومعرفة موعد استلام الصور.
* **الإدخال المرن (Forgiving Inputs):** تصحيح تلقائي ولطيف لمدخلات العميل (مثل رقم الهاتف وروابط إنستغرام) لتجنب الأخطاء.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **إطار العمل (Framework):** React.js / TanStack Start
* **قاعدة البيانات والتخزين (Backend):** Supabase (PostgreSQL, Auth, Storage)
* **التصميم والواجهات (Styling):** Tailwind CSS, Radix UI, Framer Motion
* **اللغة (Language):** TypeScript
