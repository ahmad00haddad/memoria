# مشاكل العلاقة بين العروس والمصوّرة: كل السيناريوهات

تاريخ: 2026-10-29.

## مبدأ المنصّة (قرار أحمد)

المنصّة **ما بتحل خلافات بعد ما تصير**. دورها إنها تمنعها من الأساس: كل شي يكون واضح للطرفين من البداية، ومكتوب ومعروض قبل ما يصير. هيك لو حدا غلط، غلطه واضح وفي إثبات إن المنصّة نبّهت عليه مسبقاً.

- **الشكاوى:** ما في نظام شكاوى. العروس عندها التقييم، وإيميل الدعم موجود.
- **العربون المدفوع:** المنصّة ما بترجّعه. أي استرجاع أو مسامحة قرار المصوّرة لحالها.
- **التأجيل:** مش خيار بالمنصّة. التأجيل يعني إلغاء وضياع العربون، إلا إذا المصوّرة سامحت أو طلبت عربون جديد لليوم الجديد. هاد بينهم.
- **محتوى الباقة:** مسؤولية المصوّرة إنها تكتب كل التفاصيل.
- **سحب موافقة النشر:** بين العروس والمصوّرة مباشرة، والمنصّة مش طرف فيه.

## اللي لازم ينبني (بعد القرارات)

| # | الميزة | التفاصيل |
|---|---|---|
| 1 | **زر إلغاء للعروس قبل العربون** | بصفحة متابعة الحجز. إلغاء مجاني بدون أي تبعات |
| 2 | **زر إلغاء للعروس بعد العربون** | قبل الضغط تظهر رسالة واضحة: "إلغاء الحجز يعني إن العربون ما بيرجع. إذا بدك تحاولي تسترجعيه، تواصلي مع المصوّرة مباشرة. القرار إلها والمنصّة ما بترجّع عربون مدفوع." + تأكيد |
| 3 | **توضيح التأجيل** | جملة ثابتة بصفحة المتابعة وقبل الدفع: "التأجيل مش متاح من المنصّة. تغيير الموعد = إلغاء وحجز جديد، إلا إذا المصوّرة وافقت تنقل العربون" |
| 4 | **توضيح دور المنصّة قبل دفع العربون** | صندوق موافقة: العربون ما بيرجع، والتأجيل والاسترجاع بين الطرفين. بينحفظ وقت الموافقة كإثبات |
| 5 | **المبلغ المتبقي** | بعد يوم العرس: تذكير للعروس تحوّل باقي المبلغ (المبلغ + طريقة التحويل). المصوّرة تشوف بحجزها "العروس لسا ما حوّلت المتبقي" مع نصيحة: استنّي وذكّريها قبل ما تسلّمي الصور. زر "استلمت المتبقي" بيسكّر التنبيه. المصوّرة حرّة تسلّم قبلها |
| 6 | **فريق التصوير: نسائي / رجالي / مختلط** | حقل بملف المصوّرة + فلتر بالبحث. الفريق الرجالي لتصوير الجاهات |

**بحاجة قرار:** في كود قديم لاسترداد العربون (`deposit_refund_policy` بقيم full/partial/none و `processDepositRefund`). إذا العربون بيندفع عبر Zbooni لحساب المنصّة، المنصّة هي اللي ماسكة المصاري، وعملياً هي اللي بترجّع. لازم نقرر: نشيل سياسة الاسترداد من الإعدادات، ولا نخلّيها اختيار للمصوّرة (هي بتقرر، والمنصّة بتنفّذ قرارها بس)؟

## المرجع: كل السيناريوهات

ملاحظة: الجداول تحت كُتبت قبل القرارات فوق. أي حل مقترح فيها بيتعارض مع "مبدأ المنصّة" (شكاوى، نزاعات، تأجيل من المنصّة، سحب موافقة النشر) **ملغي**.

**الحالة:** ✅ موجود · 🟡 موجود جزئياً · ❌ غير موجود · ❔ لم يُتحقّق منه

## 1. قبل الحجز: البحث والثقة

| السيناريو | الحالة | ملاحظة / الحل |
|---|---|---|
| حساب مصوّرة وهمي أو صور مسروقة | 🟡 | في توثيق (`verification`) وشارة Pro. **أضف:** بلاغ "صور مش إلها" من الصفحة العامة → الأدمن |
| صفحة فاضية بتطلع للعامة | ✅ | صُلّحت: مخفية لحد ما تكمل الإعداد |
| الأسعار المعروضة مش هي الحقيقية ("السعر تغيّر") | 🟡 | السعر بينحفظ بالحجز. **أضف:** قفل السعر من لحظة الطلب حتى لو المصوّرة عدّلت الباقة |
| العروس بدها تسأل سؤال قبل ما تحجز | ❌ | الرقم خاص. **أضف:** "اسألي سؤال" يوصل عبر المنصة (تيليجرام/إيميل للمصوّرة) |
| مقارنة بين مصوّرات | ✅ | `compare.functions` موجودة |

| أسلوب المصوّرة مش واضح (ألوان، تعديل) | 🟡 | المعرض موجود. **أضف:** "شاهدي عرس كامل" بدل صور منتقاة بس |
| مناسبة خاصة بالنساء: لازم مصوّرة أنثى وفريق نسائي | ❔ | **أضف:** حقل "الفريق: نسائي بالكامل / مختلط" وفلتر بالبحث، مهم جداً بالأردن |
| تغطية خارج المدينة / سفر | ✅ | `travel_fee_per_km` و `free_km` |
| العروس ما بتعرف شو تختار | 🟡 | في دليل و FAQ. **أضف:** أسئلة سريعة (نوع المناسبة، الميزانية، الساعات) → اقتراح باقة |

## 2. طلب الحجز والرد عليه

| السيناريو | الحالة | ملاحظة / الحل |
|---|---|---|
| حجزين بنفس اليوم | ✅ | حجز واحد افتراضياً، أو أكثر بخيار المصوّرة مع تنبيه (اليوم) |
| المصوّرة ما بترد على الطلب | 🟡 | الطلب بيحجز اليوم 48 ساعة ثم يتحرّر (`booking_holds`). **أضف:** تذكير للمصوّرة بعد 12 و 24 ساعة، ورسالة للعروس "ما ردّت، شوفي مصوّرات ثانيات" مع اقتراحات |
| المصوّرة رفضت | ✅ | `rejectBookingRequest`. **أضف:** سبب رفض من قائمة + اقتراح مصوّرات متاحات بنفس اليوم |
| طلبات وهمية (حدا بيحجز أيام المنافسة) | 🟡 | تحقق هاتف (`booking_phone_verification`) وحد للطلبات المعلّقة. ✅ معقول |
| العروس كتبت تاريخ أو وقت غلط | ❌ | **أضف:** تعديل الطلب قبل الموافقة من صفحة المتابعة |
| تفاوض على السعر | ✅ | `price_offers` / عروض أسعار |
| طلب خاص مش ضمن الباقات (حنة + عرس + صباحية) | 🟡 | الملاحظات والتفاوض. **أضف:** "حجز متعدد الأيام" بطلب واحد |
| الوقت بيقطع منتصف الليل (حفلة 20:00–02:00) | 🟡 | الأوقات نهايتها قبل البداية. ❔ تحقّق من الفورم: `end<=start` ممكن يترفض بالسيرفر (`duration <= 0`) |
