# قائمة فحص اختبار المستخدم الغبي (Dumb User Testing Checklist)

استخدم هذه القائمة عند فحص أو تجربة أي تحديث جديد على لوحة الإنتاج. قم باختبار كل بند ووضع علامة (✓) عند اجتيازه بنجاح.

## 1. النقر العشوائي والسريع
- [ ] ماذا يحدث عند النقر المزدوج (Double-Click) على زر "التالي" بسرعة؟ (يجب ألا يتم تحريك الحجز مرتين وألا تتكرر رسائل النجاح).
- [ ] ماذا يحدث عند النقر على جميع أزرار التحريك في نفس الوقت في حجوزات مختلفة؟ (يجب أن يعمل أول نقر، ويمنع الـ Overlay بقية النقرات حتى ينتهي التحميل).

## 2. اختبار فقدان الاتصال بالشبكة (Offline Simulation)
- [ ] قم بفصل الإنترنت (عبر DevTools) وحاول تحريك حجز. (يجب أن تظهر رسالة خطأ حمراء واضحة، مع بقاء الحجز مكانه دون تشوه البيانات).
- [ ] قم بفصل الإنترنت وافتح صفحة لوحة الإنتاج. (يجب عرض رسالة خطأ مفهومة وزر "إعادة المحاولة").

## 3. التعامل مع البيانات غير الصالحة
- [ ] حاول نقل حجز إلى مرحلة "اختيار الصور" وهو لا يمتلك `selection_link`. (يجب أن يُرفض النقل وتظهر رسالة واضحة ترشد لإضافة الرابط).
- [ ] حاول تعديل مرحلة حجز مغلق `completed`. (يجب أن تظهر رسالة أن الحجز مغلق، ويُفضل إخفاء أزرار التحريك أصلاً).

## 4. الوضع الداكن والفاتح
- [ ] تحقق من قراءة نصوص البطاقات وألوان الخلفيات `bg-*-50` أو `bg-secondary` في وضع Dark Mode. (يجب ألا تكون النصوص غامقة على خلفية غامقة، أو الألوان باهتة).
- [ ] تحقق من تباين مؤشر الـ "Due Date" (الأحمر، البرتقالي، الرمادي) في الوضع الداكن والفاتح.

## 5. تجربة الجوال (Mobile Experience)
- [ ] افتح اللوحة بشاشة عرض عرضها 375px. (يجب أن يظهر التبديل بين الأعمدة بشكل أزرار أفقية).
- [ ] بعد نقل حجز، تأكد أن التبويب النشط `activeStage` يتحدث تلقائياً ليُظهر المرحلة الجديدة للحجز المنقول.
- [ ] تأكد من مساحة النقر لأزرار التحريك (يجب أن تكون كافية ولا تضغط بالغلط على اسم العميل).

## 6. الجلسات المنتهية وصلاحيات الأمان
- [ ] قم بمسح كوكيز الجلسة (Clear Cookies) وحاول النقر على أي شيء. (يجب أن يتم توجيهك إلى صفحة الدخول مع تمرير `?redirect`).
- [ ] حاول تحميل حجوزات مصور آخر بتغيير الـ ID في الطلب (إن أمكن برمجياً). (يجب ألا يرجع الخادم أي بيانات بفضل `eq("photographer_id", uid)`).
