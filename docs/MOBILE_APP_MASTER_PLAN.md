# الخطة الشاملة: تجربة الهاتف كتطبيق حقيقي — 2026-11-09

**الهدف:** المصوّرة تفتح Memoria من شاشة الهاتف فتشعر أنه تطبيق: يفتح فوراً، يعرف ماذا تحتاج الآن، كل شاشة فيها قرار واحد، لا تضيع ولا تعيد خطوات.

**مقياس النجاح (نختبره مع 3 مصوّرات بعد كل مرحلة):**
| المقياس | الهدف |
|---|---|
| مصوّرة جديدة تنشر صفحتها من الهاتف بلا مساعدة | ≤ 10 دقائق |
| فتح التطبيق حتى ظهور المحتوى | ≤ 0.5 ثانية (من الكاش) |
| الانتقال بين الصفحات | ≤ 100ms، بلا دوّار أبداً |
| تأكيد عربون / الرد على طلب | ≤ 3 لمسات من الإشعار |
| أطول صفحة على الهاتف | ≤ 3 شاشات تمرير قبل الطيّ |
| «حاسّة صعب» | لا أحد من الـ3 يقولها |

---

## ✅ ما أُنجز اليوم

- الإعداد يظهر من أي صفحة، و«تخطّي» يؤجّل ولا يلغي، والجولة التلقائية متوقفة.
- الأسعار: بطاقات مطوية (الصفحة من 18,700px إلى 2,470px)، بلا انزلاق جانبي.
- شريط علوي صغير (لوحتي + جرس) وشريط سفلي واحد في كل مكان.
- الرئيسية: رقم واحد، 4 أدوات مرتّبة بالأهمية ثم **الأحدث فتحاً أولاً**.
- الإعدادات: 4 ثيمات و«تخصيص متقدم» مطوي. رسائل واتساب بكلمات بدل رموز.
- السرعة: طلبات الرئيسية 33 → 24، والصفحات تُرسم فوراً من الكاش (40–150ms)، وجلب خلفي لملفي/الأسعار/الإنتاج.
- **كل صفحة تتذكّر مكان التمرير**: الرجوع للوحتي يعيدكِ لنفس المكان.

---

## المرحلة A — الإحساس بالتطبيق (أسبوع)

1. **انتقالات أصلية**: View Transitions API — الصفحة الفرعية تنزلق من الجانب، والرجوع ينزلق للخلف، وتبويبات الشريط السفلي تتبدّل بلا حركة (مثل iOS).
2. **إيماءة الرجوع**: سحب من حافة الشاشة = رجوع (iOS يدعمها في PWA مثبّت؛ نضيفها لأندرويد).
3. **هياكل بدل الدوّار**: كل صفحة لها skeleton بنفس شكل محتواها؛ `PageLoader` الكامل يُحذف من اللوحة نهائياً.
4. **ضغطات تُحسّ**: ردّ فعل لمسي فوري (scale 0.97 + اهتزاز خفيف) على كل زر أساسي؛ أهداف لمس ≥ 44px (الفحص وجد أزراراً بارتفاع 28px).
5. **تحديث بالسحب** في كل قائمة (موجود في الرئيسية فقط الآن).
6. **Bottom sheets بدل الصفحات** للأفعال القصيرة: حجب يوم، إضافة باقة، تأكيد عربون، نسخ رابط — تبقى في مكانك.
7. **الحفظ التلقائي** في ملفي والأسعار والإعدادات (مسودة كل ثانيتين + «حُفظ ✓» صغيرة)؛ لا زر «حفظ» عائم ولا تحذير «تغييرات غير محفوظة».
8. **حالة بلا إنترنت**: شريط صغير «بلا اتصال — نعرض آخر نسخة»، والأفعال تُصفّ وتُرسل عند عودة الاتصال.
9. **شاشة بداية وأيقونة** بهوية Memoria، ووضع standalone كامل (بلا شريط المتصفح)، ولون شريط الحالة يتبع الثيم.
10. **تذكّر كل شيء**: التبويب المفتوح، الفلتر في الحجوزات، القسم المفتوح في ملفي، مكان التمرير (✅ أُنجز).

## المرحلة B — تصميم خاص بالهاتف (أسبوع)

11. **الرئيسية = «اليوم»**: بطاقة واحدة كبيرة لأهم فعل الآن (طلب ينتظر ردّك / عربون وصل؟ / تسليم غداً)، تحتها قائمة قصيرة «بعدها»، ثم الأدوات. لا شيء آخر.
12. **صفحة الحجز** = بطاقة هوية الحجز (اسم، تاريخ، المبلغ المتبقي) + **زر واحد للخطوة التالية** + تبويبات (نظرة/محادثة/إنتاج). الباقي مطوي.
13. **قائمة الحجوزات**: سحب البطاقة يميناً = واتساب، يساراً = الخطوة التالية. تجميع «يحتاج ردّك» أولاً.
14. **ملفي**: معالج بأقسام قابلة للطي، كل قسم ✓ أو «ناقص»، والمعاينة الحية زر واحد.
15. **التقويم**: الشهر + لمسة على يوم = sheet (حجز/حجب/تفاصيل). الإعدادات (مزامنة، عطلة أسبوعية) خلف ⚙️.
16. **الأسعار**: إضافة باقة = 3 حقول (الاسم، السعر، الساعات)، الباقي «تفاصيل إضافية».
17. **الإعدادات** تقسم إلى «صفحتي» (شكل) و«عملي» (عربون، فريق، حجوزات اليوم) — شاشتان قصيرتان.
18. **لغة واحدة بسيطة**: مراجعة كل نص؛ لا «إفصاح»، لا «Basic limits»، لا أرقام عمليات. جمل ≤ 12 كلمة.
19. **إظهار تدريجي**: العقود/التقارير/سنتي/الإحالة تظهر بعد أول حجز مؤكّد؛ قبله لا وجود لها.
20. **نظام تصميم للهاتف**: 3 أحجام نص فقط، تباعد 8/16/24، بطاقات بزاوية واحدة، أيقونة واحدة لكل مفهوم (الآن «رسالة» تُستخدم لـ3 أدوات مختلفة).

## المرحلة C — سرعة بلا انتظار (3–4 أيام)

21. **دالة `dashboard_summary` واحدة** (RPC) بدل 14 طلباً للرئيسية → طلب واحد ~300ms.
22. **TanStack Query لكل صفحات اللوحة** مع حفظ الكاش في IndexedDB: فتح التطبيق صباحاً يعرض بيانات الأمس فوراً ثم يتحدّث.
23. **Realtime** للحجوزات والإشعارات: الطلب الجديد يظهر بلا تحديث.
24. **تحديثات متفائلة**: تأكيد العربون/نقل مرحلة الإنتاج يظهر فوراً ويُرسل في الخلفية (مع تراجع عند الفشل).
25. **صور**: مصغّرات WebP بحجم الشاشة + تحميل كسول + blur placeholder.
26. **Service Worker**: تحديث صامت للنسخة الجديدة عند الإغلاق، لا «حدّث الصفحة».
27. **ميزانية أداء**: فحص تلقائي قبل كل نشر (حجم JS، عدد الطلبات ≤ 8 للرئيسية).

## المرحلة D — يعمل وأنتِ بعيدة عنه (3–4 أيام)

28. **إشعارات Push** (بعد تثبيت الـ PWA): طلب جديد، عربون وصل، تسليم غداً — كل إشعار يفتح الشاشة الصحيحة مع الفعل جاهزاً.
29. **أفعال من الإشعار**: «قبول» / «واتساب» مباشرة.
30. **دعوة التثبيت** في اللحظة الصحيحة (بعد أول حجز، لا عند الدخول)، مع شرح iOS بصورة.
31. **مشاركة سريعة**: Web Share API لرابط الصفحة وفاتورة الحجز.
32. **اختصارات الأيقونة** (PWA shortcuts): حجز جديد، حجب يوم، الحجوزات.

## المرحلة E — قياس لا تخمين (مستمر)

33. تسجيل أحداث بسيطة: خطوة الإعداد التي توقّفت عندها، الوقت حتى النشر، الأدوات الأكثر فتحاً، الصفحات التي يُرجع منها فوراً.
34. لوحة أدمن صغيرة «أين يتعثّرن».
35. جلسة اختبار شهرية مع مصوّرتين جدد على هواتفهن (نراقب بلا مساعدة).
